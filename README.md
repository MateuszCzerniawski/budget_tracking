# Budget Tracking
This is upload of a demo UI with backend made in React and Flask, made in 2026.
It shows ability to work with React.

# Set Up

### Backend

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate        # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

The API runs on http://localhost:4444.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

The app runs on http://localhost:5173.
